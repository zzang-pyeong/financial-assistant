규율로 이긴다

시장엔 항상 정보 시차가 있다. "먼저" 안다는 것 자체가 환상에 가깝다. 그래서 이 도구는 속도 경쟁을 포기하고, 대신 결정의 순간에 확증 편향과 감정을 억제하는 마찰을 설계했다.

문제대응
정보 시차풀 수 없음 — 전제로 수용, 데이터 신선도만 투명하게 노출
감정 개입의지로 억제 불가 → 자동산출 + 확인 강제로 마찰 지점 이동
확증 편향양쪽 근거를 나란히 둬도 편향된 쪽만 골라봄 → 반대 관점부터 강제 노출
측정 불가능성도구 밖 행동을 못 보면 효과 검증 불가 → 매매일지 자동 기록

A비대칭 노출

사용자 의도의 반대편을 항상 먼저, 더 크게 보여준다. 확인 전엔 다음 단계로 못 간다.

B병치, 비집계

지표를 하나의 점수로 합치지 않는다. Peer 비교·소유구조도 병치만 하고 종합 게이지는 없다.

C마찰은 설계된 것

손절·익절·수량은 자동 산출하되, 근거를 확인해야만 진행된다 — 마찰이 입력에서 확인으로 옮겨갔다.

D정보 제공, 자금관리 아님

계좌 자본·리스크 허용비율처럼 개인 재무 상태를 밝혀야 하는 입력은 강제하지 않는다. 종목의 객관적 지표만 다룬다.

어떻게 동작하나 · 8단계 흐름

8단계, 그중 3곳은 그냥 못 지나간다

데이터는 병렬로 모으지만, 사용자가 보는 화면은 순서가 있다. 굵은 테두리로 표시된 3단계는 확인 없이는 넘어갈 수 없는 강제 관문이다.

02 · Peer 비교 그룹

텅스텐·베릴륨·감자칼륨 회사까지 "동종 희토류"로 섞여 들어옴을 뒤늦게 발견

만들면서 오간 질문과 답

손절·익절을 기술적 지표로 어떻게 잡을 것인가?
손절은 여러 후보 중 가장 보수적인 값(MAX), 익절은 50%를 가까운 목표(MIN)로 확정하고 나머지 50%는 추격손절로 트레일링.
실적 발표가 임박하면 어떻게 하나?
변동성이 커지니 포지션 사이징에 축소 배수(×0.5)를 적용하기로 함.
Peer 중에 진짜 같은 업종은 어떻게 가려내나?
Finnhub 산업분류로 후보를 넓게 뽑고, 사업 설명 텍스트의 키워드로 2차 필터링해 Tier1/Tier2로 구분.
애널리스트 매수의견의 실제 근거를 모아볼 수 있나?
목표가 컨센서스·개별 등급변경 API는 실제로 호출해보니 유료 전용이었다. 대신 뉴스에서 "price target", "initiates coverage" 같은 키워드로 관련 기사만 근사 필터링.
Peer 비교에서 PER만 보는 건 위험하지 않나?
실제로 peer 7종목을 확인해보니 trailing PER은 2/7, PEG는 2/7만 채워졌다 — 적자 소형주 섹터에선 이익 기반 지표가 통계적으로 무력화된다. EV/Revenue·유동비율· 부채비율·현금 런웨이(보유현금÷연간FCF소진액)를 추가했더니, PER로는 그냥 "데이터 없음"이었던 EMAT이 실제론 런웨이 4개월·당좌비율 0.10짜리 유동성 위기라는 게 드러났다.
계좌 자본·리스크 허용비율까지 입력받아야 하나?
아니다 — 이 도구의 목적은 개인 자금관리가 아니라 객관적 매매 정보 제공이다. 사용자의 실제 재무 상태를 밝히게 하는 입력은 UX에도, 취지에도 안 맞는다고 판단해 제거했다. 대신 계좌 $10,000·리스크 1%라는 기본 가정으로 계산한 "참고용 예시"만 보여주고, 실제 매수 수량은 사용자가 직접 정하게 했다 (원칙 D).
