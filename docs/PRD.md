# EnterTicker PRD

## 제품 정의

EnterTicker는 한글 기업명, 영문 기업명, 또는 티커로 미국 상장기업을 검색해 가격, 밸류에이션,
동종기업 비교, 소유구조, 뉴스, 옵션, 기업 간 연결 정보를 한 자리에서 빠르게 탐색하는 웹
리서치 도구다. 검색 직후 뜨는 Conflict Board는 그 종목을 둘러싼 상승·하락 근거를 카테고리별로
나란히 병치해, 단일 점수나 추천 없이 핵심 쟁점을 먼저 파악하게 하는 첫 요약 화면이다.
Conflict Board는 제품 전체가 아니라 탐색의 시작점이며, 사용자는 여기서 관심이 가는 축을
골라 상세 화면으로 이동한다.

## 대상 사용자와 문제

한국어로 미국 주식을 조사하려는 개인 투자자를 대상으로 한다. 이들은 보통 여러 데이터
사이트와 탭을 오가며 가격·재무·수급·뉴스를 따로따로 찾아야 하고, 한글 기업명만 알 때는
정확한 티커를 찾는 것부터 막힌다. 또한 단일 점수나 추천을 그대로 받아들이기보다, 서로 다른
데이터와 원문을 직접 확인하고 스스로 판단하고 싶어 한다.

## 목표

- 한글/영문 기업명 또는 티커 중 무엇으로 검색해도 탐색을 시작할 수 있게 한다.
- 가격·기술적 맥락·밸류에이션·동종기업·소유구조·뉴스·옵션·기업 연결 정보를 하나의 조회
  맥락 안에서 제공한다.
- 사용자가 궁금한 질문에 맞는 상세 화면으로 빠르게 이동하도록 안내한다.
- 데이터의 출처, 기준 시점, 결측·근사치 여부를 명확히 구분해 보여준다.

## 비목표

- 매수·매도 추천이나 투자 자문을 제공하지 않는다.
- 자동 주문을 실행하지 않는다.
- 포지션 사이징이나 계좌 단위 리스크 관리를 하지 않는다.
- 손절가·익절가를 자동으로 산출하지 않는다.
- 매매일지나 포트폴리오 관리 기능을 제공하지 않는다.
- 기관급 실시간 데이터 터미널을 대체하지 않는다.

## 핵심 사용자 흐름

```text
기업명/티커 검색
  → Conflict Board에서 핵심 쟁점 파악
  → 관심 축 선택
     (차트 / Peer Compare / Ownership Map / Analyst News / Company Events / Options Data / Connection Map)
  → 근거와 원문을 확인하거나 다른 종목 검색
```

## 주요 화면

- Conflict Board: 이 종목의 상승·하락 논점은 무엇인가?
- Price Chart: 가격 흐름과 거래량은 어떤 모습인가?
- Peer Compare: 유사 기업과 밸류에이션·재무 특성이 어떻게 다른가?
- Ownership Map: 기관·내부자·공매도·유통주식 관련 수급 구조는 어떤가?
- Analyst News: 최근 애널리스트 의견 관련 보도는 무엇인가?
- Company Events: M&A, 경영진 변화, 계약 등 기업 이벤트는 무엇인가?
- Options Data: 단기 옵션의 미결제약정과 거래량은 어떤 분포인가?
- Connection Map: 검색한 기업이 어떤 기업과 연결되어 있고, 그 연결이 자회사·지분 보유·
  M&A·계약/제휴 중 무엇이며, 어떤 근거로 확인되는가?

Connection Map은 관계마다 근거의 성격과, 확인된 경우의 방향을 함께 보여준다. 자회사
(SEC Exhibit 21)와 대량 지분 보유(Schedule 13D/13G)는 구조화된 공식 문서에서 직접
확인되며 방향(모회사→자회사, 투자자→피투자사)도 표시된다. 뉴스에서 포착한 M&A·공급/
고객 계약·전략적 제휴·합작투자·라이선싱은 보도 근거로 표시되고, 방향은 문장 구조로
판단 가능할 때만(예: M&A의 인수자/피인수자) 표시하며 그 외에는 추측하지 않는다. 공시에
이름이 함께 언급됐을 뿐 관계 유형이 불분명한 항목은 기본 화면에서 숨기고, 토글을
켜야만 노출된다. 근거 개수나 관계 유형으로 강도·투자 매력도를 점수화하지 않는다.

## 데이터 신뢰성 원칙

- 데이터 출처와 기준 시점 또는 갱신 상태를 화면에 표시한다.
- 값이 없는 것과 오류로 못 가져온 것을 구분해 표현한다.
- 근거의 성격(구조화된 공식 문서 vs 뉴스 보도 vs 단순 언급)이 다르면 화면에서 구분해
  보여준다(예: 단순 언급은 기본적으로 숨김).
- 관계나 사실이 확실하지 않은 필드(방향, 지분율 등)는 추측해 채우지 않고 빈값 또는
  "미확인"으로 남긴다.
- 키워드 기반 뉴스 분류와 관계 매칭은 근사치일 수 있음을 표시한다.
- 비공식 또는 무료로 제공되는 데이터의 지연·누락 가능성을 명시한다.
- 투자 조언이 아니라는 고지를 상시 노출한다.

## 성공 지표

투자수익률을 지표로 삼지 않는다. 대신 아래를 본다.

- 검색 성공률
- 첫 분석 화면 로딩 성공률 및 로딩 시간
- 상세 화면 탐색률
- 뉴스/공시 원문 클릭률
- 7일 재방문율
- 데이터 오류·결측 상황에서의 이탈률

## 출시 기준

- 검색 실패, 데이터 없음, 로딩 실패를 구별해 안내한다.
- 주요 데이터에 출처와 기준 시점 또는 갱신 상태를 표시한다.
- 투자 조언이 아니라는 점과 데이터가 지연될 수 있다는 점을 고지한다.
- 핵심 탐색 행동(검색, 화면 이동, 원문 클릭)을 측정할 수 있다.
