- 정밀 검토(8단계 강제 흐름)와 매매일지 기능을 라이브 앱에서 제거
- 손절/익절 자동산출 로직도 함께 비활성화(코드는 아카이브에 보존)
- Peer List 페이지를 Peer Compare 페이지에 통합(사이드바 8개→7개 항목)
- Peer Compare에 Current Ratio, Operating Margin, Gross Margin, EV/EBITDA, 매출성장률
  (YoY) 지표 추가
- Peer Compare에 재무 특징 서술형 코멘트 추가(규칙 기반, 새로운 판단 없음)
- Ownership Map에 "기관+내부자 합계" 항목 추가(두 수치가 100%로 안 합산됨을 명시)
- 사이드바 세션 초기화 링크를 "시작화면으로"로 개명해 검색창 위에 작게 재배치
- 모든 서브페이지 헤더(타이틀·티커·뒤로가기)를 중앙 정렬로 통일
- Options Data: 콜 OI 합계가 0인 만기에서 발생하던 크래시 수정
- Options Data: 행사가별 상세 테이블 정렬 기준을 미결제약정(OI)에서 거래량(volume)으로 변경
- Price Chart: 일봉 기간 라디오 버튼의 기본 선택 표시가 실제 표시 중인 기간(6개월)과
  불일치하던 문제 수정
- 사이드바에 현재가+당일 변동률 표시 추가(상승 빨강/하락 파랑, 티커+가격 한 줄)
- 사이드바 세션 초기화가 서브페이지에서 눌렀을 때 중간 화면을 한 번 더 거치던 문제 수정
  (`st.switch_page`로 바로 이동)
- Relationship Map: SEC 공시 검색을 양방향으로 확장(대상 종목 공시 + 상대 회사 공시 모두
  검색) — 정방향만으론 못 잡던 상대방(예: 자기 공시에만 언급을 크게 실은 소형주) 포착
- Relationship Map: 정적 "이미 아는 회사" 목록에 우주/방산·희토류/critical minerals·
  암호화폐 채굴 카테고리 추가(~100개 → ~120개)
- Relationship Map: 그래프 위에 상대기업 수·뉴스 근거 수·SEC 공시 근거 수를 분리 표시
